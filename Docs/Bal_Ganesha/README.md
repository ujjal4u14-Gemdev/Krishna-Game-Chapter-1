# Bal Ganesha Chapter 1 — Production Pack

This folder is the content source of truth for the Bal Ganesha adaptation. The original walkthrough analysis remains in `Docs/Chapter_1_Level_Matrix.md` as mechanical reference evidence; production must use the documents below.

## Locked scope

| Item | Decision |
|---|---|
| Chapter title | **Bal Ganesha and the Festival of Wisdom** |
| Levels | 54, unchanged |
| Arc A | Levels 1–25 — **The Missing Modaks** |
| Arc B | Levels 26–54 — **The Shadow Naga Cave** |
| Puzzle families | 13 Erase/Reveal, 15 Binary Choice/Route, 26 Aim & Shoot |
| Target | Unity `6000.0.84f1`, Android, portrait 1080 × 1920 |
| Content policy | Original artwork, dialogue and audio; do not copy the reference game's assets |

## Non-negotiable reuse rule

The level number and puzzle family are immutable. A content designer may change narrative text, palette, prop skin, animation, VFX and audio, but may not change the successful interaction or hazard layout without creating a separately reviewed design revision.

## Cultural review

This is an original family-game adaptation inspired by familiar Bal Ganesha imagery, not a claim that the chapter is a canonical scripture story. Character depiction, dialogue, gestures, symbols and festival details require review by the project's cultural consultant before final voice recording and release.
